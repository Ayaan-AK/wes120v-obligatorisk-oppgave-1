# Nettsted

Bruk av Vite og github for å hoste nettsted.

## Krav

- [Node.js](https://nodejs.org/) må være installert
- [pnpm](https://pnpm.io/) må være installert

## Installasjon

Installer avhengighetene:

```bash
pnpm install
```

## Utvikling

Start sserveren:

```bash
pnpm dev
```

Åpne via terminalen(`http://localhost:5173`).
